# LORE - trusted signers (EXPERIMENTAL / provisional TEST HARNESS)
#
# Names the OpenPGP signing keys that count as LORE authority, and at what LEVEL.
# It is the "allowed_signers" root for Track F (forensic integrity, Option C), and it
# makes CORE-INVARIANT 11 (authority has lineage) executable: trust is bound to the
# SIGNING-key fingerprint (role), and every accepted signature must additionally CHAIN
# to a `root` key (lineage), which the verifier enforces.
#
# STATUS: conceptual test harness, explicitly intended to be replaced by robust key
# management (HSM / hardware token, rotation, revocation, multi-party custody). Not
# production trust infrastructure. See META-CONTEXT/forensic-integrity.accepted.md.
#
# ROLES
#   root             - the author-authority root (KF-01). Author-hand acts. The raw
#                      evidence manifest is a ROOT-ONLY act.
#   delegated:agent  - a signing subkey the author delegates to an agent, so the agent
#                      may sign LOWER-trust artifacts under a key whose lineage traces to
#                      the author primary - without ever wielding the root. The agent
#                      holds only this subkey's secret in real use.
#
# GOVERNANCE: only the author edits this file. An agent must never sign with a `root`
# key, nor add/relabel entries. Adding a delegated key is an author act (it is certified
# by the author primary at key-creation time).
#
# FORMAT: one entry per line -  <40-hex signing-key fingerprint>  <role>  <label>
# '#' lines and blank lines ignored. Whitespace-separated; label may contain spaces.
