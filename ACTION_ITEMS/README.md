# ACTION_ITEMS

**Action items** - forward-looking work that requires **planning or response**. Distinct from a
decision already made, a lesson learned in retrospect, or a principle: an action item is a tracked,
governed TODO with an owner and a disposition.

## Lifecycle
- `open/` - raised, awaiting planning/response. Status `open`.
- **resolved** - moved out of `open/` (to `resolved/`, or status `resolved`) with a note on what happened.

## Convention
Each action item records: the **activity**, the **why** (context/trigger), the **response/plan
needed**, and **provenance** (what raised it). The author sets priority and disposition.

## Public export note
Individual action items are not published in the public export (they are private working records).
This directory and its subdirectory structure are published so the governance layout is visible.
