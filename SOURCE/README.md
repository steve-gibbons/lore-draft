# LORE Corpus — the volumes

This is the **substance of LORE**: ~130 short volumes (v0.2 draft) exploring the model from every
angle — ontology, trust, authority, provenance, governance, lifecycle, and more. The governance
scaffold in the rest of this repository exists to *govern* this content.

> EXPERIMENTAL / PROVISIONAL, v0.2 draft. Exploratory, not settled.

## Start here — the five core volumes (`CORE-VOLUMES/`)
Read these first, in order — the whole model in five reads:
1. **Volume 0 — Origin, Philosophy, and Design Intent** ← start here
2. Volume 1 — Core Ontology and Semantic Model
3. Volume 2 — Trust, Security, and Authorization
4. Volume 3 — Resilience, Continuity, and Lifecycle
5. Volume 4 — Implementation and Ecosystem

Everything else deepens a facet.
